
# Практическая работа № 6

Объектно-ориентированное программирование.

Выполнил: Азаровский В. Д., группа 09с41.

## Описание

Программа обрабатывает анкеты студентов и преподавателей.
Проверяет правильность ФИО, электронной почты и телефона.
Выводит статистику и сохраняет результаты в текстовые файлы.

## Файлы проекта

- people.py — классы Person, Student и Teacher.
- registry.py — обработка и хранение анкет.
- main.py — запуск программы.
- anketa.txt — примеры анкет.
- test_checks.py — проверки программы.
- Разминка — пять дополнительных заданий.

## Запуск

Для работы нужен Python 3.

В терминале выполнить:

python main.py

Результаты сохраняются в ok.txt и errors.txt.
